# 🚧 Development Roadmap

This roadmap outlines the planned evolution of **Monster Slayer** as the project grows from a simple combat game into a fully featured RPG.

---

# ⚔️ Version 1 — Core Combat

Version 1 is dedicated to creating a complete, playable combat system.

## 🎯 Objectives

| Goal         | Description                                                  |
| ------------ | ------------------------------------------------------------ |
| **Gameplay** | Build a complete combat loop.                                |
| **Scope**    | Gameplay logic only.                                         |
| **Focus**    | Heroes, Monsters, Combat, Status Effects, and Special Moves. |

---

## 📝 Version 1 Backlog

- Monster Special Moves

---

## 🎨 Version 1 Presentation

Once the combat system is complete, Version 1 is considered feature complete.

---

# ⚔️ Version 2 — Game Modes

Version 2 expands the core combat game by introducing multiple ways to play.

## 🎮 Main Menu

Players choose between two game modes before selecting their hero.

### Dungeon Mode

- Fight 4 Monsters
- Defeat the Final Boss
- Complete the Run

### Onslaught Mode

- Endless Monster Battles
- Survive as Long as Possible
- Record and Display a High Score

---

## 📈 Expansion

Version 2 focuses on expanding gameplay content.

- Additional Heroes
- Additional Monsters
- Bosses
- More combat variety

---

# ⚔️ Version 3 — Presentation

Version 3 transforms the console game into a polished desktop application using Tkinter.

## Focus Areas

- Main Menu
- Hero Selection Screen
- Combat Interface
- Health Bars
- Menus
- Images and Sprites
- Animations (Lite)
- Sound and Music
- Overall User Experience

---

# 🌟 Long-Term Vision

Monster Slayer ultimately grows into a replayable roguelite RPG featuring:

## Gameplay

- Turn-Based Combat
- Elemental Damage System
- Status Effects
- Hero Progression
- Boss Encounters
- Endless Onslaught Mode
- Dungeon Runs

## Progression

- Loot
- Consumable Items
- Relics
- Persistent Unlocks
- Multiple Hero Classes
- NPCs and Story Progression

## Combat Evolution

- Party-Based (3 vs. 3) Battles
- Attribute Based Turn Order
- Telegraphed Enemy Attacks
- Team Synergies
- Advanced Tactical Combat

## World Building

- Story
- Lore
- Character Development
- Expanded Enemy Factions

## Replayability

- Endless Runs
- High Scores
- Unlockable Content
- Procedurally Increasing Difficulty
